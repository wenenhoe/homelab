# Decision drafts

Decisions that depend on something not yet verified — see
[`../README.md`](../README.md#drafts) for what that means and how
promotion to a real, numbered ADR works. Unnumbered, freely rewritten
or deleted in place; nothing here should be cited as settled by
anything outside this directory.

Use [`TEMPLATE.md`](TEMPLATE.md) for new drafts.

`Status` is the draft's own frontmatter (`Draft` / `De-risking` /
`Decided` — see [`../README.md#drafts`](../README.md#drafts) for what
each means). `Project` is generated by scanning `docs/projects/*.md`
for an actual link to the draft, not a hand-maintained field — so it
can't drift from what's really wired up. A `—` here isn't a gap to
fill in: some drafts are genuinely single-PR-scoped and were never
going to get a project (see
[`../../projects/README.md`](../../projects/README.md#when-this-is-the-right-artifact)
for what actually needs one), while others — check the draft's own
Context — still need a scoping pass before anyone can tell which case
they're in.
