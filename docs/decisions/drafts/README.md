# Decision drafts

Legacy. Drafts are being converted into `working` revisions of decision
lineages — see [`../README.md#drafts`](../README.md#drafts). Nothing new
starts here, and nothing outside this directory should cite a draft as
settled. A new decision starts as a lineage, from
[`../TEMPLATE.md`](../TEMPLATE.md).

`Status` is the draft's own frontmatter (`Draft` / `De-risking` /
`Decided`). `Project` is generated by scanning `docs/projects/*.md` for a
link to the draft, so it can't drift from what's wired up. A `—` isn't a
gap: some drafts are single-PR-scoped and never needed a project (see
[`../../projects/README.md#when-this-is-the-right-artifact`](../../projects/README.md#when-this-is-the-right-artifact)).
